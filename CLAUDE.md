# Writing for this site

Before writing or editing any page copy or blog post, read the guides in `content-guide/`:

1. `humour.md`
2. `voice.md`
3. `opinions.md`
4. `stats.md` — the only numbers allowed
5. `stories.md` — the only anecdotes allowed

Keep the site's existing brand name and design. These guides are for tone and content only.

Do not use the B2B cyber security SaaS case study ($2M → $7M ARR, 142 demos, 3.8x) on this site — it's an outbound result.
The $7.2M figure may be used as "generated for clients, collectively".
